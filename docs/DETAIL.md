# 终端运行 (Run in terminal)

把对话里的 shell 代码块变成可执行的一行操作：点一下按钮，命令直接在右侧栏的终端里敲进去并回车，输出留在终端里，可以继续交互。

## 用法

1. 对话中出现 `bash` / `sh` / `zsh` / `console` / `powershell` / `cmd` 等语言的代码块时，语言标签右侧会出现 **▶ 终端** 按钮。
2. 点击按钮：
   - 右侧栏若没有本会话的终端，自动新建一个终端标签页并展开侧栏；
   - 已有该插件用过的终端，直接聚焦复用；
   - 等待终端就绪后写入命令并回车。
3. 按钮上的状态会短暂显示 `发送中…` → `✓ 已发送`，失败时显示 `✗ 失败`，悬停可看原因。

## 行为细节

- **不劫持输入**：命令是通过该终端标签页自己的连接写入的，写入后输入焦点仍归你，可以接着在同一个终端里继续敲命令。
- **只在需要时新建**：每个会话复用同一个由本插件打开的终端标签页；不会碰你自己开的终端，也不会碰 Agent 的终端。
- **终端已结束**：如果那个终端已经退出，会自动关掉它并新开一个再执行。
- **多行代码块**：整段文本一次写入并回车，shell 会按行顺序执行。

## 已知限制

- 只对 shell 语言代码块生效，其它语言（python、js 等）不显示按钮。
- 命令以你的系统用户身份在终端里运行，权限与手敲一致，不受 Agent 沙箱约束——点之前请自己确认命令内容。
- 若右侧栏面板被宿主禁用或终端能力未装配，按钮会显示失败且不会执行任何命令。

## 卸载

在插件管理中停用「终端运行」即可；停用后代码块恢复原样，已打开的终端标签页不受影响。
